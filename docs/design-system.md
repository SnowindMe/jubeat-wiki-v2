# jubeat 音乐魔方 WIKI v2 · 设计系统

> **冻结版本：r1 · Blue Candy Cabinet**  
> 适用范围：全站 Astro 静态页面与原生交互增强。该文档连同 `src/styles/tokens.css` 是视觉令牌的唯一来源。

## 修订设计计划

### 产品锚点

这是面向 jubeat 音乐魔方国服玩家的中文可追溯资料站。用户的首要动作是**找曲、辨认谱面等级/定数、追溯字段来源**；因此清亮的视觉氛围必须让位于扫读效率，不能把资料站做成只看一眼的赛事 Landing Page。

### Color

| 名称 | Hex | 用途 |
|---|---:|---|
| 云雾白 | `#F8FCFF` | 页面主底、正文可读基底 |
| 冰晶白 | `#FFFFFF` | 卡片、浮层和 Hero 按键亮面 |
| 浅空蓝 | `#DDF5FC` | 背景光晕、选中面、低对比区域 |
| 机台青 | `#20C8E6` | **唯一交互强调色**：链接、焦点、当前项、Hit-Line |
| 深海蓝 | `#126C9D` | 标题、可读性较强的交互文字 |
| 墨蓝 | `#17334D` | 正文和高权重数据 |

难度颜色为领域专用语义，不能被挪作按钮/状态主色：BSC `#168BC8`、ADV `#C47A00`、EXT `#D54872`。来源徽标为中性蓝灰，不抢夺难度或交互意义。`#CF9CF4` 粉紫仅作为糖果玻璃反射/展示标题的极少量辅助高光，绝不成为第二互动强调色。五池色同样属于 `/unlock/` 页面私有语义，不能外溢到全站 CTA。

### Type

- **Display（站名、页面标题）**：`"Arial Rounded MT Bold", "Microsoft YaHei", ui-rounded, system-ui, sans-serif`。圆润的字形仅用于少量大标题，回应糖果机台的亲和感，不做全站卖萌字体。
- **Body（说明、考据、表格文本）**：`"Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`。中文优先，默认 16px / 1.65，保障长考据阅读。
- **Data（ID、时间、数值、来源码）**：`ui-monospace, "Cascadia Code", Consolas, monospace`。仅用于需要逐字对齐和扫描的资料字段。

字号用 `--w-fs-*` 统一；标题压缩字距仅限 display 角色。禁止加载外部字体，以满足零字体请求预算。

### Layout

内容壳宽 `--w-shell: 1240px`；桌面保持资料主栏，移动端以 12px 页面边距和不低于 42px 的控件高度服务触控。卡片列数只由容器决定，不能以固定卡宽导致页面横滚。

```text
┌──────────────────── sticky global nav ────────────────────┐
│  4×4 mini mark  站名       曲目库 数据 图鉴 关于  搜索   │
├───────────────────────────────────────────────────────────┤
│  Hero: 资料定位 / 快捷检索          4×4 蓝白糖果按键      │
├──────────── stat cards ────────────┬── updates / notices ─┤
│  曲目库：搜索 / 筛选 / 排序          │                     │
│  [song card] [song card] [song card] [song card]          │
│  cover · title · difficulty chips · source / metadata     │
└───────────────────────────────────────────────────────────┘

375px: nav drawer → Hero 单栏 → 统计 2 列 → 曲目卡 1 列
768px: Hero 双栏或紧凑双栏 → 统计 3 列 → 曲目卡 2 列
1440px: 居中 shell → 曲目卡 3–4 列（按容器而非视口硬锁）
```

### 背景系统（官方风格参照的抽象重建）

以 `player_home_bg.png` 的**构图与纹理语法**为核心参考，但不复制、嵌入或裁切该图。背景由 CSS 组合而成：天空蓝至冰蓝的干净渐变为底；左上角布置一组低不透明度、小尺寸的 4×4 方格；右下角布置更大、向右上斜切延展的 4×4 方格，其中可有一格略亮；从左下斜切到右上的浅蓝光带/导轨内嵌细点阵或短线节奏。它们都必须位于正文之后、低对比显示，不能承载信息，也不能干扰资料扫读。

移动端仅保留一组小尺寸低对比方格和淡化的斜向光带；右下大方格隐藏。实现建议使用 `body::before/after` 或独立 `.w-ambient` 容器及其伪元素，搭配 `linear-gradient`、`radial-gradient`、`repeating-linear-gradient`，禁止引入图片素材。

### Signature

1. **4×4 蓝白糖果按键**：Hero 的主构图，严格 1:1 的十六格；白/浅青半透明格叠在冰蓝光晕上，仅三格点亮以对应 BSC/ADV/EXT。也可缩小为导航徽标、无曲绘几何占位与版面分隔节奏，但不以赛事图、人物或版权 Logo 充当视觉资产。
2. **菱形分区入口**：首页四分区（曲目库 / 数据 / 图鉴 / 关于）以小型菱形图标框配合**完整文字链接**呈现。菱形来自按键与用户中心的斜切几何语法，不是无标签图标按钮；不能把所有按钮都做成菱形，更不能使用胶囊。
3. **资料卡片系统**：白色/半透明白面板 + 青蓝 1px 描边 + 温和浮起状态。曲目卡的曲绘使用白底描边“封套/唱片卡”槽；三难度小标签、来源标签、原机种/解禁元信息均有固定位置，保证扫读与缺图降级。
4. **Hit-Line**：鼠标悬停或键盘焦点进入结果行/卡片时，在顶部显示 2px 机台青命中线；仅用于“当前可操作资料项”，而非所有面板。

### `/unlock/`：糖果实验室管线与五池进度卡

解禁页专用 `.w-pool-card` 采用圆润白卡、斜切池名角标、进度条和低负担的 CSS 抽象管路（细线、半透明“试管”容器、液面渐变），从官方解禁路线的实验室语法转译而来，但不复制任何原始 UI、角色、Logo 或素材。五个池色只在池标识、进度与管路液面中使用：CHERRY `#ED7397`、KUMQUAT `#F5A443`、LIME `#82BD52`、BLUEBERRY `#568FE0`、RAINBOW `#B47AE6`。管线不使用持续流动动画；低动效模式下完全静止。

## 与旧三稿/模板审美的差异与自我批判

旧三稿（信号网格、档案控制台、节奏账本）均探索过暗底、高密度资料表达；本次最终方向**主动放弃黑底荧光的默认技术产品脸**，改用蓝白空气感。这不是把 WIKI 降格成赛事海报：亮底反而让来源、定数与长篇考据在长时间阅读时更轻松，青蓝强调也更贴近蓝白机台按键的触感。

同时刻意避开两个常见模板陷阱：

- 不使用漂浮渐变球、玻璃拟态大面积堆叠或大号 KPI 作为 Hero 主角；背景点阵和光晕只维持低对比氛围，真正的 Hero 主角仍是 4×4 面板与检索入口。
- 不用过度圆角、彩虹色按钮或无意义动画制造“糖果风”。圆角仅服务面板可分辨性，难度三色只标识难度，互动色始终只有机台青。

**为什么这不是泛用蓝色 SaaS / 游戏 Landing Page**：4×4 格不是抽象装饰，而是 jubeat 的实际触控面板；菱形入口继承按键/用户中心的斜切几何，仍保留文字任务入口；五池实验室卡将解禁这一独有资料结构转换成可比较的“管线 + 池标识”；背景的左上小格、右下斜格与斜向导轨则来自机台玩家首页的空间语法。四者共同指向“音乐魔方的资料操作”，而不是套在任何产品上的蓝色渐变。

**刻意克制**：粉紫只用作标题与玻璃反射的一笔高光；五池彩色不离开解禁页；密集表格与详情正文下不铺高对比纹理；曲绘保持封套槽而非背景海报；不使用液体流动、漂浮糖果或循环发光。这样糖果元素能标记功能与方向，而不会降低定数、来源和考据的可读性。

**风险与约束**：浅色系统最容易在弱层级下显得发白、在大量卡片中失去资料密度。因此正文使用墨蓝、边框保持可见青蓝灰，表格可在大屏使用紧凑行而非强制卡片；曲绘缺失用 4×4 几何占位，绝不生成伪图。柔影仅作为轻微抬升反馈，常态层级首先靠底色、边界与排版完成。

## 令牌使用规则

- 所有视觉值从 `tokens.css` 的 `--w-*` 令牌消费；组件禁止硬编码颜色、圆角、阴影、间距与动效时间。
- 强调色只用 `--w-hit` 和 `--w-hit-deep`。难度令牌只给难度文本、难度条与难度标签；不得用于普通 CTA、链接或来源。
- 使用 `--w-panel` / `--w-panel-glass` 区分可读面板与叠于背景光晕的半透明面板。常态不使用阴影，hover/focus 才可用 `--w-shadow-lift`。
- 所有卡片和容器遵守 `--w-r-*`（12–24px）；小数据徽标不做胶囊，使用 `--w-r-xs`（4px）。
- 间距以 4px 基数，最小可触目标用 `--w-tap`（42px）。

## 品牌 Logo（主人授权的全站资产）

主人已授权 `Jubeat音乐魔方.png` 作为全站品牌资产。核心实现将其落入 `public/` 后，顶栏品牌位、首页 Hero、404 和分享图均使用**原始比例与黑白粗轮廓**；不重绘、不改造字形、不添加会削弱识别的滤镜。

- **最小尺寸**：顶栏桌面宽度不小于 132px、移动端不小于 104px；Hero 不小于 180px；404 可为 144px；分享图不小于 240px。高度始终由 `auto` 保持原比。
- **安全区**：Logo 四周至少保留其渲染高度的 20% 空白，任何文字、4×4 格、装饰光带和裁切边缘不得侵入。
- **承载面**：蓝白糖果背景上必须置于白色或半透明白色面板/足够白底区域，保证黑白粗轮廓清晰；只允许无色 `drop-shadow` 以分离极浅底色，优先不加滤镜。
- **移动端**：顶栏使用 104–132px 宽，Hero 以 `min(56vw, 220px)` 限宽；不得把 Logo 压缩成无辨识的图标，也不得与汉堡菜单争抢触控空间。
- **禁止事项**：不得拉伸、倾斜、裁切文字、描边改色、渐变填充、反相、添加发光/模糊/液化特效，或将其作为背景水印。不可用 CSS/Canvas/SVG 临摹替代正式授权文件。

### Global navigation

- 高度：`--w-nav-h`；白色半透明底并可 `backdrop-filter` 降级为不透明白底。
- 桌面显示四个一级分区；768px 以下转为原生 `<details>` 抽屉。当前项使用底部命中线 + 深海蓝文字，不能仅靠颜色传达状态。
- 所有页面提供 `.w-skip-link`，`main` 具唯一落点。

### 面板与卡片

- 大区块：`.w-panel`，使用 `--w-r-lg`；内部卡 `.w-card` 使用 `--w-r-md`。
- 卡片信息顺序固定：曲绘/占位 → 曲名与 artist → 难度 → 来源与元信息。缺图仅替换曲绘槽，不移动字段。
- 结果卡可用 `.w-hit-target` 获得命中线。hover 只能短暂改变边框/面板/轻影，不移动文档流。

### Difficulty chip 与 source badge

- `.w-difficulty` 必带 `data-difficulty="bsc|adv|ext"`；颜色与边框来自难度令牌，文字必须显式含难度名或可访问名称。
- `.w-source-badge` 为中性、可聚焦的矩形标签；当有冲突时搭配 popover，展示全部来源值。来源标签绝不伪装成难度标签。

### 表单、筛选、数据表

- 输入控件最小高度 `--w-tap`；有常驻 `<label>` 或可访问名称。
- 筛选栏采用 `auto-fit / minmax()`；绝不设置造成窄屏横滚的固定组宽。
- 768px 以下完整表格可转为 `.w-song-grid` 卡片，或置于**容器内** `overflow:auto`，页面 body 不得横滚。

### 4×4 panel

- `.w-pad-4x4` 使用 4 列网格、`aspect-ratio: 1`，每格 `.w-pad-key` 使用白/浅青表面。
- 点亮格以 `data-difficulty` 叠加相应难度边框/柔光；无障碍说明在图形外给出，纯装饰图形加 `aria-hidden="true"`。

## 可访问性、动效与响应式

- 文字色 `--w-ink` 与云雾白底保持正文级对比；链接/焦点除颜色外有描边或命中线。
- `:focus-visible` 使用 3px 机台青环和 3px offset，不能被 `overflow:hidden` 截断。
- 仅允许 120 / 200 / 320ms 三档转场；`prefers-reduced-motion: reduce` 关闭 transition、transform、scroll behavior。禁止持续循环动画。
- 容器统一 `width: min(100% - 2 * var(--w-s-3), var(--w-shell))`；图片 `max-width:100%`；正文页面 `overflow-wrap:anywhere`，作为 375/768/1440 无横溢出的最后防线。
